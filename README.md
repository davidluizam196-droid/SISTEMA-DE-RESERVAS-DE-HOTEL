# 🎯 Objetivo

Desarrollar un sistema de software funcional para la **gestión de reservas de un hotel de mediana capacidad**, integrando los principios de la **Programación Orientada a Objetos (POO)**, **estructuras de datos lineales** y **algoritmos de búsqueda y ordenamiento**, garantizando la persistencia de la información mediante una **base de datos relacional administrada con DB Browser for SQLite**.

- 📅 Gestión de reservas.
- 👤 Registro de clientes.
- 🔎 Búsqueda de habitaciones disponibles.
